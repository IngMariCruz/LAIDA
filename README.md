# LAIDA 🤖💬

LAIDA es una plataforma que combina un bot de Telegram con una aplicación web
para la captura y gestión de leads de una PYME, utilizando IA y analítica de datos.

---

## 🧠 Arquitectura

- Frontend: Next.js (React)
- Bot: Python (python-telegram-bot)
- Base de datos: SQLite
- IA: Embeddings (en progreso)
